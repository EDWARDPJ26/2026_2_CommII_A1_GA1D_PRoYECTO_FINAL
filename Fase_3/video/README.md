Pruebas por aire a 870 MHz del enlace BFSK para telemetría industrial:

- **Transmisor:** NI USRP 2920 con `Transmisor_FSK_USRP_Ruido.grc` (UHD: USRP Sink).
- **Receptor:** HackRF One con `Receptor_FSK_HackRF_Ojo.grc` (osmocom Source).
- **Verificación:** analizador de espectro, con los radios a unos 3 m.
